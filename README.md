\# Spring Security - Week 14



Bài tập Spring Security gồm 3 ví dụ.



\## ViDu1 - Spring Security Login



\- Login với Spring Security

\- User và Role

\- Phân quyền USER / ADMIN

\- Thymeleaf

\- MapStruct

\- SQL Server



\## ViDu2 - Custom Login



\- Login bằng Username hoặc Email

\- Custom UserDetails

\- Hiển thị thông tin User trên Header

\- Phân quyền USER / ADMIN

\- Thymeleaf

\- MapStruct

\- SQL Server



\## ViDu3 - Security + OTP + CRUD + Cloudinary



\### Authentication



\- Register

\- Gửi và xác nhận OTP

\- Resend OTP

\- Login bằng Spring Security Session

\- Logout

\- Forgot Password

\- OTP Reset Password

\- Đổi mật khẩu bằng BCrypt



\### User



\- CRUD User

\- Search User

\- Pagination User

\- ROLE\_USER / ROLE\_ADMIN

\- Đếm tổng User

\- Đếm Product của từng User



\### Product



\- CRUD Product

\- Search Product

\- Pagination Product

\- Product thuộc User

\- Upload ảnh Cloudinary

\- Xóa và thay ảnh Cloudinary

\- Hiển thị User sở hữu Product

\- Thymeleaf

\- SQL Server
